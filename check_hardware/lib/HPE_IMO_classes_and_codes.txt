- **Class (Integer)** The Class field identifies the structural classification or major **hardware subsystem** where the event occurred.** What it means in your log:**
	- **Known Subsystem Classes**
		- **Class 1 (0x01):** Memory Subsystem *(e.g.,   Advanced ECC errors, multi-bit ECC, or configuration errors)*
		- **Class 2 (0x02):** Environmental /  Thermal Subsystem *(e.g., Temperature thresholds, fan failures, system   overheating)*
		- **Class 3 (0x03):** Power Subsystem *(e.g., Power supply failures, power redundancy lost)*
		- **Class 4 (0x04):** System Architecture / Motherboard *(e.g., General system board faults)*
		- **Class 5 (0x05):** CPU / Processor Subsystem *(e.g., Uncorrectable Machine Check Exceptions [MCE],  processor faults)*
		- **Class 6 (0x06):** PCI Subsystem *(e.g., PCI bus errors, device failures)*
		- **Class 8 (0x08):** System Core / Revision Status *(Tracks system hardware/BIOS/POST configuration changes or revisions)*
		- **Class 9 (0x09):** Operating System *(Logs events triggered by OS interactions or unexpected software halts)*
		- **Class 10 (0x0A):** Storage / Smart Array Controllers *(e.g., Array controller errors, cache backup battery missing/faults)*
		- **Class 11 (0x0B):** Storage Devices & Smart Storage Energy Pack *(e.g., Drive failures, energy pack pre-failure states)*
		- **Class 17 (0x11):** Network / NIC Subsystem *(e.g., Adapter link down or port transitions)*
		- **Class 20 (0x14):** Hardware Fault / Mezzanine Components *(Often used in Synergy interconnect configurations or broad hardware critical faults)*
		- **Class 50 (0x32):** System Management Recovery *(Commonly logs Unexpected Shutdowns and Restarts where the system recovers from an undetermined error)*

# Corrections verified against live hardware

## Class 5, Code 4 - corrected 2026-10-18

**Was documented as:** Processor Interconnect Link (QPI / UPI) Failure.

**What it actually is on AMD ProLiant hardware:** an *Uncorrectable Machine
Check Exception - Extended Registers* record. This is the register-dump
companion entry that iLO writes alongside the Class 5 / Code 3 MCE, not a
separate interconnect fault.

**Evidence** (atlhwe-lsf24-sp, ProLiant Gen10, AMD, IML read 2026-10-18):
Class 5/4 occurs 104 times and Class 5/3 occurs 82 times, interleaved over the
same minutes of 2025-06-29 to 2025-07-07. Every 5/4 message begins
"Uncorrectable Machine Check Exception Extended Registers (Conf 0x..., Ipid
0x..., Synd 0x..., DeStat 0x..., DeAddr 0x... Misc1 0x...)". Not one mentions
an interconnect, QPI or UPI link.

QPI and UPI are **Intel** interconnects; this fleet's ProLiants are AMD, which
uses Infinity Fabric. The original entry appears to be Intel-platform guidance
applied to the wrong architecture.

**Consequence if uncorrected:** a 5/4 storm reads as a motherboard or CPU-link
fault and sends a technician after the wrong part, when the actionable signal
is the paired 5/3 MCE (and, on this host, the Class 10 / Code 644 DIMM
failure that was driving it).

**Encoded in** `lib/iml_map.sh`, which describes it as the extended register
dump and retains the documented interconnect reading as a secondary
possibility for Intel platforms.
